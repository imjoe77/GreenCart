# 🛒 GreenCart

GreenCart is a PHP and MySQL based e-commerce web application developed as part of an academic server-side development project.

The application demonstrates fundamental backend development concepts including authentication, database interaction, CRUD operations, shopping cart functionality, and an administrative dashboard.

---

## 🌐 Features

- User Registration & Login
- Product Catalog
- Shopping Cart
- Checkout Process
- Admin Dashboard
- Product Management
- Database Integration

---

## 🛠 Tech Stack

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

---

## 📚 Concepts Demonstrated

- Server-side Rendering
- CRUD Operations
- Session Management
- Authentication
- Database Connectivity
- Form Handling

---

## 🎓 Project Context

This project was developed as part of a college server-side development course to gain practical experience with PHP and MySQL web application development.

---

## Note

This project is a server-side PHP and MySQL application. It requires a local or PHP-enabled hosting environment to run and therefore is not deployed on GitHub Pages.
